# AI Agent Roadmap

从 Python 基础开始，逐步学习前后端开发和 AI Agent 开发。

## 学习路线

- [ ] 第一阶段：Python 基础
- [ ] 第二阶段：HTML / CSS / JavaScript
- [ ] 第三阶段：React 前端开发
- [ ] 第四阶段：FastAPI 后端开发
- [ ] 第五阶段：数据库与前后端联调
- [ ] 第六阶段：LLM API、RAG 与 Agent
- [ ] 第七阶段：完整 AI Agent 项目

## 目录说明

- `python/`：Python 学习与练习
- `frontend/`：前端开发
- `backend/`：后端开发
- `agent/`：Agent 技术
- `projects/`：综合项目
- `notes/`：学习笔记
- `docs/`：规划与文档

## 目标

掌握独立开发、测试、部署 AI Agent 应用的能力，并积累可用于实习求职的项目经验。
